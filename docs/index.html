Deep-learning–powered cerebral aneurysm detection from medical imaging

Product Overview

The Aneurysm Detection System is a research-grade deep learning pipeline for detecting cerebral aneurysms in medical images (DICOM, PNG, JPG). It implements multiple state-of-the-art neural network architectures and a suite of post-processing methods to reduce false positives, making candidate detections more clinically meaningful for expert review.

The project includes two runtime interfaces: a Streamlit web application for interactive exploration and visualization, and a FastAPI backend that exposes the detection pipeline as a REST API.

This project is based on research published on arXiv (paper 2507.00832). It is intended for research and educational purposes only.

Key Features

  • Multiple detection models: CPM-Net 3D-CNN-TR Ensemble — choose individual models or combine for higher accuracy.
  • Flexible input formats: DICOM (.dcm), PNG, and JPG images are supported.
  • Dual runtime interface: Interactive Streamlit web app for visual exploration; FastAPI REST backend for programmatic integration.
  • Five post-processing methods for false-positive reduction, with Method 5 achieving up to 70.6% FP reduction for CPM-Net and 51.6% for 3D-CNN-TR.
  • Upload pipeline: Upload images, trigger processing, poll status, retrieve results — all via clean REST endpoints.
  • Auto-generated API docs available at /api/docs (Swagger UI) and /api/redoc (ReDoc).

Getting Started

Prerequisites

  • Python 3.8 or higher
  • pip package manager
  • CUDA-capable GPU (recommended for inference speed)

Streamlit Web Application

The interactive front-end lives in:

generate_code/aneurysm_detection_postprocessing/aneurysm_app/

Install dependencies:

cd generate_code/aneurysm_detection_postprocessing/aneurysm_app/
pip install -r requirements.txt

Run the app:

streamlit run app.py

The app will be available at http://localhost:8501

FastAPI Backend

The REST API backend lives in:

backend/

Install dependencies:

cd backend/
pip install -r requirements.txt

Run the server:

uvicorn app.main:app --reload

The API will be available at http://localhost:8000

Interactive API docs: http://localhost:8000/api/docs

API Reference

The FastAPI backend exposes four primary endpoints under the /api/v1/aneurysm/ path prefix.

Method Endpoint Description
POST /api/v1/aneurysm/upload Upload an image file (DICOM / PNG / JPG) for processing. Returns an upload_id.
POST /api/v1/aneurysm/process/{upload_id} Trigger detection pipeline for the given upload. Accepts model and post-processing options.
GET /api/v1/aneurysm/status/{upload_id} Poll the processing status (queued / running / complete / failed).
GET /api/v1/aneurysm/results/{upload_id} Retrieve detection results including bounding boxes, confidence scores, and post-processed candidates.
Auto-generated docs
Swagger UI: http://localhost:8000/api/docs

Post-processing Methods

Five false-positive reduction methods are implemented. Method 5 (Combined Ensemble) yields the highest reduction and is recommended for production-research use.

Method Name FP Reduction — CPM-Net FP Reduction — 3D-CNN-TR
1 Brain mask filtering — removes false positives outside the brain region Partial Partial
2 Artery proximity filter — uses artery segmentation mask Moderate Moderate
3 Vein exclusion filter — removes venous false positives Good Good
4 CVS mask filter — combined cerebrovascular mask High High
5 ★ Full anatomy ensemble — all methods combined, 0 TP lost (Recommended) 70.6% 51.6%

★ Method 5 combines all preceding methods in a voting ensemble. These figures are derived from the research described in arXiv paper 2507.00832.
